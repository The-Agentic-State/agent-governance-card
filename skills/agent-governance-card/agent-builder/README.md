# Agent Builder variant (Microsoft 365 Copilot)

For teams whose only assistant is Microsoft 365 Copilot. Agent Builder cannot
install a skill, run a script, or read `.yaml`/`.md` files, so this folder
carries the same card in the three shapes it accepts. Card **v0.4**, derivation
contract **3**. Same rules as the skill; the difference is that the Impact
Level is derived from the written rules, not the engine — so the card says so
and asks for engine verification before filing.

| File | Use in Agent Builder | Source |
|---|---|---|
| `instructions.txt` | Paste into **Instructions** (cap: 8,000 characters). | Hand-condensed from [`../SKILL.md`](../SKILL.md); kept under the cap by `schema/build.py --check`. |
| `agent-governance-card.schema.txt` | Add as a **knowledge file**. | Byte-identical copy of [`../references/schema.snapshot.yaml`](../references/schema.snapshot.yaml), generated by `schema/build.py`. Do not edit. |
| `card-template.txt` | Add as a **knowledge file**. | Byte-identical copy of [`../templates/card-template.md`](../templates/card-template.md), generated by `schema/build.py`. Do not edit. |

## Set-up (about ten minutes)

1. In Microsoft 365 Copilot choose **New agent → Skip to configure**.
2. **Name:** Agent Governance Card. **Description:** "Interviews a product team and fills in the Agent Governance Card for one agentic system, computes its Impact Level, and emits the card."
3. **Instructions:** paste the contents of `instructions.txt`.
4. **Knowledge:** upload `agent-governance-card.schema.txt` and `card-template.txt` as files. Turn on **Only use specified sources**.
5. **Capabilities:** leave code interpreter and image generator off.
6. **Starter prompt:** "Help me fill in the Agent Governance Card for our new agent."
7. Test on **Try it**, then share with your organization.

## Two things to know

- **Government Community Cloud (GCC) tenants cannot embed files.** Put the
  two `.txt` files in a SharePoint site instead and add that site or those
  files as the knowledge source; the instructions work unchanged.
- **The level is prose-derived.** Before filing, re-check it with the engine:
  `python3 scripts/derive_impact.py fill.json` from the published skill, or
  through the CCF submission form. The engine is the source of truth for the
  Impact Level; the written rules in `instructions.txt` restate it.
